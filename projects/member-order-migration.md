# 會員與訂單資料遷移工具

> Member and Order Migration Toolkit · C# / .NET 8 · WPF · Playwright · ClosedXML

## 解決的問題

商家更換營運系統時，會員、歷史訂單、出貨單和商品明細可能來自不同報表。這個 Windows 桌面工具把分段匯出、資料關聯和匯入前檢查整合成一套流程，讓操作人員能追查每筆問題來自哪份報表。

## 我做的功能

- **分段匯出與續跑。** 使用 Playwright 操作經授權的來源介面。歷史訂單依日曆月切段，記錄每份來源檔的期間、列數及雜湊，並保存可續跑的進度。
- **Excel 整理與欄位映射。** 使用 ClosedXML 分開保存會員、原始訂單、出貨單及品項明細，產出目標格式的會員預檔。保留原始狀態和識別碼，供後續查證。
- **跨月完整性檢查。** 比較分月結果與整段匯出的資料列，並針對月末與月初交界、重複來源、內容衝突和無法關聯的會員列出問題。
- **離線匯入前預檢。** 產出 Excel 驗證摘要及文字、JSON 報告。待確認的欄位規則和匯入條件會列為阻擋項目。

## 驗證範圍

開發版曾用一段跨兩個月份的資料驗證分月與整段匯出的資料列一致性，也另外匯出月末和月初的資料核對邊界。驗證涵蓋已選期間與匯入前檢查，歷史全量與目標系統正式寫入仍待驗收。上表為作品集用合成資料。
