# Profile Introduction - English / Japanese

## English Version

Hi, I'm Arille. I build practical operations tools that connect software engineering with real business workflows.

My work focuses on SaaS backends, merchant admin consoles, browser automation, Excel-driven tools, desktop launchers, and legacy system modernization. I enjoy taking repetitive or unclear manual processes and turning them into systems that are easier to run, monitor, and maintain.

My portfolio includes an IBirdy SaaS commerce backend, a Vue-based merchant operations console, an electronic invoice value-center prototype, a Playwright-powered auto-listing publisher, and a PHP-to-Python legacy migration project.

I care about software that works beyond the happy path: clear inputs, safe defaults, useful logs, recoverable errors, and documentation that helps real users operate the system with confidence.
