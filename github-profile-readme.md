# Hi, I'm Arille

I build practical operations tools for small business workflows: SaaS backends, merchant admin consoles, browser automation, Excel-driven publishing tools, and legacy system modernization.

My strongest work sits at the edge between business operations and software engineering. I like turning messy manual processes into systems that people can actually use: APIs, dashboards, background jobs, desktop launchers, automation scripts, diagnostics, and clear operating documents.

## Selected Projects

### IBirdy SaaS Commerce Operations API

ASP.NET Core backend prototype for commerce operations, including JWT authentication, SQL Server persistence, EF Core/Dapper data access, Swagger API docs, Hangfire jobs, audit logs, and LINE/Facebook messaging integration boundaries.

**Tech:** ASP.NET Core, SQL Server, Entity Framework Core, Dapper, JWT, Hangfire, Swagger

### IBirdy Merchant Operations Console

Vue 3 SaaS operations console for admin, merchant, and customer workflows. The system includes product upload, order management, campaigns, billing, usage, alerts, audit logs, value-center pages, merchant subscriptions, social commerce modules, Chrome extension support, and an IBirdy auto-post toolkit.

**Tech:** Vue 3, Vite, Pinia, Element Plus, axios, Chart.js, Playwright, Node.js

### Electronic Invoice Value-Added Center

Node.js proof of concept for a Taiwan electronic invoice value-added center. It includes API-first invoice creation, idempotency handling, Turnkey-style queue simulation, worker retries, HMAC-signed webhooks, Docker setup, and operational readiness documents.

**Tech:** Node.js, REST API, Worker Queue, Docker, HMAC, Webhooks

### JJ Auto Listing Publisher

Windows desktop automation prototype for branch-store posting workflows. It reads Excel post plans, matches rows to media folders, controls Chrome through Playwright/CDP, publishes scheduled posts, writes status back to Excel, and includes launcher, installer, updater, repair flow, diagnostics, and usage docs.

**Tech:** Playwright, Node.js, xlsx, Chrome CDP, .NET WinForms

### Legacy PHP To Python Port

Legacy modernization project that inventories PHP entry controllers, maps routes into Python metadata, preserves assets, catalogs SQL schemas, and creates a runnable Python web migration foundation. This project shows how I approach large existing systems: understand first, map the risk, then migrate incrementally.

**Tech:** Python, PHP migration, Flask/FastAPI path, Jinja2 path, Docker, Playwright

## How I Think About Software

I care about making software usable in the real world. A tool is not finished just because the happy path works. It needs clear inputs, recoverable errors, safe defaults, logs, setup notes, and enough documentation that someone else can run it without guessing.

The projects here are mostly prototypes and internal case studies, but they show the way I build: start from a concrete workflow, make the system executable, then keep tightening the parts that reduce manual work and operational risk.
